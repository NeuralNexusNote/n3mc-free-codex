# Security policy

[日本語](#セキュリティポリシー)

## Reporting a vulnerability

If GitHub's private vulnerability reporting is available for this repository, use **Security → Report a vulnerability**. Do not put credentials, memory database contents, or a working exploit in a public issue. Include the affected version, steps to reproduce, and potential impact in the private report.

This project is supplied as is by an individual developer. A response time or fix is not guaranteed. The policy covers this repository's Codex code and instruction documents. Report problems in Codex, Python dependencies, or embedding models to their maintainers.

# セキュリティポリシー

## 脆弱性の報告

このリポジトリでGitHubの非公開の脆弱性報告が利用できる場合は、**Security → Report a vulnerability** から報告してください。認証情報、記憶DBの内容、攻撃手順を公開Issueに書かないでください。非公開の報告には、影響する版、再現手順、想定される影響を記載してください。

本プロジェクトは個人開発者が現状のまま提供します。報告の確認、返信や修正の時期は保証できません。対象はこのリポジトリのCodex用コードと指示書です。Codex、Pythonの依存パッケージ、埋め込みモデルの問題は、それぞれの提供元へ報告してください。
